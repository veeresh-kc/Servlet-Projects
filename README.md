# 🧾 Registration Form using Java Servlets

A simple Java Servlet-based web application that demonstrates handling form data using **Servlets** and **HTML forms**.  
It collects user registration details and displays them back in a structured HTML table.

---

## 🚀 Features
- Collects user information from an HTML form.
- Handles multiple qualifications using `getParameterValues()`.
- Displays the submitted details dynamically using a Servlet.
- Uses `@WebServlet` annotation (no web.xml configuration required).
- Compatible with Apache Tomcat 9 or higher.
